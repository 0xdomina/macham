Why it is safe

The store sets the price. Not the browser.

Server-priced

Every amount comes from the store's own catalog. A tampered price is refused.

Capture matches

PayPal captures exactly the approved total, then the order is checked again.

Per store, kept

Orders are scoped to each store key and saved, so a retry never charges twice.

Install

One script tag. Your store keeps its checkout.

Paste this before the closing body tag.

<script src="https://YOUR-MACHAM-HOST/macham.js" data-key="mch_live_..." defer></script> <script> Macham.init({ apiKey: "mch_live_...", tenantId: "my-store", assistUrl: "https://YOUR-MACHAM-HOST", }) </script>
