# Macham assist

Store-agnostic commerce assistant. Shoppers search, compare, and approve.
Prices are fixed by the store — no negotiation, no seller console. Money
moves on PayPal rails with human approval. Audit anchors on Rialo.

## Use it

Point the widget at any store adapter. The merchant holds one `mch_` key.
Model keys stay server-side, metered per key.
